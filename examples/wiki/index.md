# Home

Welcome to your wiki. Every page is a plain Markdown file in this folder, and wikiBits shows
them as a browsable, editable wiki.

## Start here

- [[getting-started]] explains pages, links, images and the keys.
- [[notes/markdown-cheatsheet]] shows what the renderer can draw.

## Sections

Folders group pages, and every folder has an `index.md` that stands for the folder: [[/notes]]
opens the Notes folder's page. This page is the root `index.md`, the wiki's home.

> Tip: press `?` at any time to see the keys, `e` to edit this page, `N` to create one.
